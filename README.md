# PDF Toolkit

Comprime, une, edita y convierte PDFs en el navegador. Todo se procesa en tu dispositivo — los archivos no se suben a ningún servidor.

**Sitio en vivo:** https://pdf-toolkit-tjn6.netlify.app/

## En el iPhone (Safari)

1. Abre el enlace de arriba **en Safari** (no en Edge ni WhatsApp).
2. Toca el botón **Compartir**.
3. Elige **Añadir a pantalla de inicio**.
4. Confirma. Ya queda como app.

## Qué incluye

- Comprimir, unir, páginas (eliminar/reordenar), rotar, proteger
- Editar texto, marca de agua, crear PDF
- Extraer texto, PDF a imagen
